# Daily Sales Entry and Report System

## Overview
This project enables field salespeople to submit daily counts of sold goods through a simple interface. The backend securely stores this data and provides Excel reports for admin-level review and operational insights.

## Features
- 🧾 Salesmen can submit daily entries for items sold
- 📈 Admin can generate and download Excel reports
- 🔒 Secure login for salespersons and admins (optional)
- ☁️ Deployed via Render (Node.js) and MongoDB Atlas
- 📦 Clean API endpoints ready for frontend consumption

## Tech Stack
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Excel Generation: `exceljs` / `xlsx`
- Deployment: Render (Free Tier)
